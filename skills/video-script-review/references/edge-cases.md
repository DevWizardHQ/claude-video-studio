# Edge-case checklist

Offer these as a multi-select in the brief. Each selected item becomes a scene.

## Sign-up and verification
- OTP not received: wait 60 seconds, use Resend, check the number is right.
- OTP resend limit reached: say what the limit and the cooldown are.
- OTP still not received after several tries: contact support, show the contact.
- Wrong or expired OTP.
- Phone number already registered: go to login or recover account.
- Password too weak or confirmation mismatch.
- Required field left empty, validation messages.

## Login and recovery
- Wrong password, account locked.
- Forgot password flow.
- Two-factor code not accepted, lost device, backup codes.

## Profile and KYC
- Document photo rejected: size, blur, glare, format.
- Name or number mismatch.
- Verification pending and how long it takes.

## Always
- Network failure or slow response.
- Where to get help: phone, email, hours, in-app link.
- What the user must never share (OTP, password).
